This repo holds ONE module. It clones, installs and runs on its own — you do
not need the other 18 to work on it.

The machine-readable version of this file is `module.json`. The backend reads
it at startup to probe upstreams; if you edit one, edit both.


WHAT THIS MODULE NEEDS (upstream)
-------------------------------------------------------------------------------
Nothing here is required to START, and nothing is marked `required: true`.

M06 is the front door. A student who opened a session must be able to finish
it whichever of these is down, so each one narrows what the session can do —
and the report says which — and none of them ends the interview.

Every route and payload below was checked against the upstream's SHIPPED code
(plan_in_depth/M06_REVIEW.md, Part 1), and tests/test_contracts.py holds M06
to shapes captured from those modules' own models.

WHAT THIS MODULE FEEDS (downstream)
-------------------------------------------------------------------------------
These consume M06. They are NOT dependencies — M06 never blocks on them.

  M13   one evaluation request per answered turn
  M02   coverage ledger rows: asked, answered, skipped
  M05   a ProvisionalOutcome per strategist verdict; the items a student saw
  M04   recent sessions for the profile summary
  M01   the session id and URL for a defend drill
  M16   break depths per concept, per session
  M19   the session event log: transcript, plan, re-plans, pacing
