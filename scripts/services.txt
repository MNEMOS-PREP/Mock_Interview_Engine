#==============================================================================
#  SERVICE TABLE  -  the only file you edit to add a service.
#
#  Pipe-delimited. Blank lines and lines starting with # are ignored.
#  Fields are trimmed, so line them up however you like.
#
#    id        stable key. Also the PID file name: .run\<id>.pid
#              Prefix by module (m06-*) - start_mock.bat filters on it.
#    label     tab title, and the name in the control tab's table
#    cwd       working directory, relative to the repo root
#    requires  path (relative to cwd) that must exist, or the service is
#              reported MISSING and skipped instead of failing in a dead tab
#    command   what runs. Passed to cmd.exe, so batch syntax is fine.
#              NEVER hardcode a port here that PORTS.txt does not reserve.
#    url       what to print for a human. Blank = nothing to open.
#    health    path probed for readiness. Blank = fall back to a port check.
#
#  Ports come from PORTS.txt: M06 is API 8106, web 5206.
#==============================================================================
